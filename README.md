# Optimizing-Falcon-9-Mass-Consumption-and-Trajectory
I modeled the Falcon 9 first stage to minimize fuel consumption by optimizing its trajectory and throttle schedule. Using public data, I formulated the optimal-control problem with Pontryagin’s Minimum Principle, derived the Hamiltonian and optimality conditions, and computed a numerical solution using Hermite-Simpson direct collocation.
